# Concept2 Research Provenance

Prepared for the training app on 31 July 2026.

The report in this folder is a packaged version of the preceding Concept2
Logbook research pass. It preserves the reported endpoint paths, fields,
examples, source links, implementation evidence, and explicit uncertainty.

Evidence types are separated in `SOURCE_REGISTRY.json`:

- official Concept2/developer/terms/privacy/software sources;
- public open-source clients and model fixtures;
- published integration discussions and community reports;
- original starter code written for this bundle.

No live Concept2 OAuth account, PM5 monitor, or production webhook endpoint was
available for validation while building this archive. The starter code is
therefore intentionally conservative: it uses documented paths, preserves raw
payloads, treats missing strokes as valid, follows pagination, and exposes
unresolved questions rather than hiding them.

The report should be rechecked against the live official documentation before a
commercial launch or irreversible database migration.
